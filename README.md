# Постразговор

Игры для дома к занятию «Разговоры о важном» 9 ноября 2026 года:

- **«От мечты к открытиям. К 315-летию со дня рождения М. В. Ломоносова»** — 1–2, 3–4, 5 классы и 2–4 курсы СПО;
- **«Александра Николаевна Пахмутова и Николай Николаевич Добронравов»** — 6–7, 8–9, 10–11 классы и 1 курс СПО.

В каждой возрастной группе три игры: **Я – сам**, **Я с командой** (друзья, одноклассники, однокурсники), **Я с семьёй**. Всего 24 игры. Работает на компьютере, планшете и телефоне.

**Играть онлайн:** https://irinilou.github.io/postrazgovor/

## Как открыть

| Что нужно | Что взять |
|---|---|
| Открыть с флешки или отправить файлом | **`index.html`** в корне: один файл, внутри всё — оформление, код и фрагменты песен |
| Открыть онлайн | ссылка GitHub Pages |
| Поправить тексты или оформление | папка **`src/`** |

## Как поправить

```
src/
  index.html          ← разметка и список подключённых игр
  css/style.css       ← оформление (цвета — в самом начале файла)
  js/content.js       ← названия групп, описания, список песен и пояснения к ним
  js/core.js          ← общий каркас: навигация, игроки, таймер, звуки
  js/games/*.js       ← по файлу на игру; тексты, вопросы и карточки — в начале каждого файла
  js/beats.js         ← доли для ритм-игры (создаётся автоматически)
  audio/*.mp3         ← фрагменты песен по 45 секунд
tools/make_audio.py   ← нарезает фрагменты из полных mp3 и считает доли
build.py              ← собирает src/ в один файл index.html
```

1. Откройте нужный файл в Блокноте или VS Code и поменяйте тексты. Сохраняйте в UTF-8.
2. Проверьте: откройте `src/index.html` двойным кликом.
3. Соберите один файл: `python build.py` (нужен Python 3). Получится обновлённый `index.html` в корне.

Чтобы взять из песни другой кусок, впишите секунду начала в `START` в `tools/make_audio.py` и запустите `python tools/make_audio.py "папка с mp3"` (нужны `numpy` и ffmpeg, например `pip install numpy imageio-ffmpeg`), затем `python build.py`.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub (например, `postrazgovor`) и загрузите туда содержимое этой папки.
2. Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, папка `/ (root)` → Save.
3. Через минуту-две игры будут по адресу `https://<логин>.github.io/postrazgovor/`.

## О песнях

В игры встроены фрагменты по 45 секунд, а не песни целиком. Записи защищены авторским правом; если репозиторий публичный, фрагменты будут доступны всем. Без них игры тоже открываются, но музыкальные задания работать не будут.
